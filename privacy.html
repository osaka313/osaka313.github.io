gmail-tools プライバシーポリシー

最終更新日: 2026-10-17

1. 誰のデータを扱うか

gmail-tools は、運営者（osaka313）が自分の Google アカウントだけで使う個人用のツールです。運営者本人以外のアカウントのデータは扱いません。

2. 扱うデータ

  • Gmail: 受信トレイのフィルタとラベルの設定
  • Google Drive: 運営者が指定した Markdown ファイルの本文と、ファイル名・更新日時などの情報
  • Google アカウントのメールアドレス（どのアカウントで認可したかを確かめるため）

3. 使い方

上のデータは、運営者自身の業務（メールの整理と、業務メモの更新）のためだけに使います。広告、販売、第三者への提供には使いません。

4. 保存する場所

  • Gmail の認可情報は、運営者のパソコンの中にだけ保存します。
  • Google Drive の読み書きは、自動化サービス Make（make.com）を通して行います。Make は、実行の履歴として、読み書きしたファイルの本文を一定期間保存します。保存の扱いは Make のプライバシー通知 に従います。

5. Google API Services User Data Policy

Google API から受け取った情報の使い方と、他のアプリへの受け渡しは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. 認可の取り消し

運営者は、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも認可を取り消せます。

Summary in English. gmail-tools is used only by its developer (osaka313) with their own Google account. It accesses Gmail filter and label settings, selected Markdown files in the developer's own Google Drive, and the account's email address. The data is used only for the developer's own work and is never sold, used for advertising, or shared with third parties. Gmail credentials are stored only on the developer's computer. Google Drive access runs through Make (make.com), which keeps execution history, including file content, under its own privacy notice. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
